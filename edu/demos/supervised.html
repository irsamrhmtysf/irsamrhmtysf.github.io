K-Nearest Neighbours

KNN classifies a new point by finding the K closest training points and taking a majority vote. There is no training phase — all computation happens at prediction time.

// K-Nearest Neighbours — predict(x, y) const distances = points.map(p => ({ d: euclidean([p.x, p.y], [x, y]), c: p.cls })).sort((a, b) => a.d - b.d); const votes = distances.slice(0, K).map(p => p.c); return votes.filter(v => v === 1).length > K / 2 ? 1 : 0;
Decision Boundary

The line (or surface) that separates predicted Class A from Class B. Shape depends entirely on the algorithm.

Overfitting Risk

Complex models (high-K KNN, deep trees) memorise training data. Try XOR preset to see this happen.

Linear vs Non-linear

Logistic Regression draws a straight line. KNN and Decision Trees draw complex, non-linear boundaries.

No Free Lunch

No algorithm works best on all datasets. Try each on Circle and Linear — results vary dramatically.
