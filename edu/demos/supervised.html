K-Nearest Neighbours

KNN classifies a new point by finding the K closest training points and taking a majority vote. No training phase — all computation happens at prediction time.

// K-Nearest Neighbours function knn(trainX, trainY, query, k) { const dists = trainX.map((x, i) => ({ d: dist(x, query), y: trainY[i] })); dists.sort((a, b) => a.d - b.d); const votes = dists.slice(0, k).map(p => p.y); return votes.filter(v => v===1).length > k/2 ? 1 : 0; }
