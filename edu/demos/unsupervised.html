How K-Means Works

K-Means alternates between two steps until convergence:

STEP 1 — Assign
Assign each point to its nearest centroid using Euclidean distance.
STEP 2 — Update
Move each centroid to the mean of all points assigned to it.
// K-Means core loop while (!converged) { // Assign each point to nearest centroid assignments = points.map(p => argmin(centroids, c => dist(p,c))); // Update centroids to cluster means centroids = centroids.map((_,k) => mean(points.filter((_,i) => assignments[i]===k))); }
