How object detection works

1 · CNN Backbone

ResNet-50 extracts a rich feature map from the image — a compact representation encoding what objects might be present and where.

2 · Transformer

The DETR encoder processes the feature map. The decoder runs 100 "object queries" that each attend to different image regions.

3 · Box + Class

Each query predicts a bounding box (xmin,ymin,xmax,ymax) and a class probability. Boxes below threshold are filtered out.
