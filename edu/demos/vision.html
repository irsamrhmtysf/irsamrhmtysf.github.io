How Computer Vision Works

Step 1 · Feature extraction

CNN layers detect edges, textures, shapes. Each layer learns more abstract patterns.

Step 2 · Transformer attention

DETR's encoder attends to image patches, decoder proposes bounding boxes.

Step 3 · NMS + classify

Non-max suppression removes duplicates. Each box is assigned an object class.

// Object detection in 3 lines import { pipeline } from '@huggingface/transformers'; const det = await pipeline('object-detection', 'Xenova/detr-resnet-50'); const out = await det(imageUrl, { threshold: 0.6 }); // [{label:'cat', score:0.98, box:{xmin,ymin,xmax,ymax}}, …]
