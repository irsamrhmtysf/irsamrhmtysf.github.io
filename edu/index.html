Technology Stack

How it works

Transformers.js v4

Hugging Face's official JavaScript port. Runs ONNX-quantized models at 60 t/s in the browser via WebGPU. Powers NLP, vision, audio.

WebGPU + WASM

WebGPU gives near-native GPU acceleration for model inference. WASM fallback ensures compatibility on older devices.

Web APIs

Web Speech API for TTS. MediaRecorder + getUserMedia for audio capture. Canvas 2D for all visualisations.

Zero server

Pure static files. Open from local disk or any static host (GitHub Pages, Netlify, Cloudflare). No backend ever needed.

Model cache

Models download once from Hugging Face CDN and are cached by the browser. Works fully offline after first load.

Pure JS math

Neural network, K-Means, PCA, and evaluation demos are implemented in pure JavaScript — no library dependency for core algorithms.
